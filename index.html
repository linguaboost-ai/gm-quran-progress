Diese Seite 60-mal, jede PDF-Seite eine Lektion (A5).

Für App-Entwickler: Das SVG zeigt die Seite 1:1 als Vektorgrafik. Jeder Textpfad trägt data-lesson. Ist der Wert höchstens die gewählte Lektion, wird der Pfad schwarz, sonst grau. So deckt eine Datei alle 60 Lektionen ab. Das App-JSON enthält dieselben Pfade, dazu Wörter, Versangaben und die Lektion je Zeichen.
